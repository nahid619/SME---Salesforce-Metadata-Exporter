STEP 1: CREATE DIRECTORY STRUCTURE
================================================================================

Create the following folders:

[ ] salesforce-metadata-exporter/          (Main folder)
[ ] salesforce-metadata-exporter/config/
[ ] salesforce-metadata-exporter/core/
[ ] salesforce-metadata-exporter/exporters/
[ ] salesforce-metadata-exporter/ui/
[ ] salesforce-metadata-exporter/utils/

Quick Command (Windows PowerShell):
-----------------------------------
New-Item -ItemType Directory -Path "salesforce-metadata-exporter"
Set-Location "salesforce-metadata-exporter"
New-Item -ItemType Directory -Path "config", "core", "exporters", "ui", "utils"

Quick Command (Mac/Linux):
--------------------------
mkdir -p salesforce-metadata-exporter/{config,core,exporters,ui,utils}
cd salesforce-metadata-exporter

================================================================================
STEP 5: INSTALL DEPENDENCIES
================================================================================

Run ONE of these commands:

Option 1 (Recommended):
----------------------
[ ] pip install -r requirements.txt

Option 2 (Manual):
-----------------
[ ] pip install simple-salesforce==1.12.6
[ ] pip install openpyxl==3.1.2
[ ] pip install requests==2.31.0
[ ] pip install customtkinter==5.2.1

Verify Installation:
-------------------
[ ] python -c "import simple_salesforce, openpyxl, requests, customtkinter; print('Success!')"

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "No module named 'config'"
Solution: Ensure config/__init__.py exists

Issue: "No module named 'customtkinter'"
Solution: pip install customtkinter

Issue: Can't connect to Salesforce
Solution: Verify credentials, token, org type

Issue: Objects won't load
Solution: Wait 30-60 seconds, check terminal for errors

Issue: Export fails
Solution: Check terminal logs for specific error

Issue: Window doesn't center
Solution: Normal on some systems, manually move window
